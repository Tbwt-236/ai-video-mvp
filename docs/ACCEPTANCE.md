## 十分钟核心操作

### 1. 一键起步

新建作品，点击咖啡、花店或烘焙示例。预期：直接进入三幕编辑器，有照片、店名与文案，并能看到 AI 演示标识。无需填写密钥或上传文件。

也可选择六类门店、四种用途填写资料。「活动宣传」必须填写活动内容；其他用途可留空。

没有照片时，点击「拍摄清单」。预期：按当前画幅给出拍法，每幕有照片建议、对应字幕及素材状态；下载 TXT 可保留到手机。新模板的建议随分镜排序、复制和作品包迁移一起保留。五幕宠物门店清单已在浏览器实际下载，UTF-8 中文和全部分镜内容核对通过。

### 2. 修改作品

改一幕标题、字幕，点缩略图查看草稿预览。展开「画面构图」，修改取景、文字位置与镜头运动；调整品牌色并选择另一幕作为封面。

预期：未保存的画面可预览，点击保存后版本更新。标题最多 32 字、字幕最多 96 字。照片完整展示模式保持静止，不裁切原图。

试一次新增、复制、上移与撤销。预期：封面随分镜排序正确移动，每个副本可独立编辑；最多 8 幕，总时长不超过 60 秒。

### 3. 声音与真实视频

选择音乐风格，点击「试听 8 秒」。如支持本机中文语音，可开启配音并试听当前幕；展开分镜中的「独立口播稿」，为一幕写更完整的介绍。

选 1080p，核对「当前导出尺寸」，点击导出。预期：得到 H.264 成片，可播放与拖动；照片运动时字幕与店名保持稳定。口播较长的分镜会自动延长，页面显示真实时长。

下载整套素材 ZIP，包含视频、SRT、封面、发布文案、JSON。口播 SRT 对应实际口播，画面字幕仍保持简短。封面来自指定分镜，JSON 对应这次导出的快照。

### 4. 复用与迁移

点击「多画幅副本」，选择横屏和方形。预期：创建独立作品，照片随副本带入；打开后分别核对构图。

在原作改一段字幕后点击「另存副本」。预期：当前草稿保存在独立作品中，原作品保存版本不被替换。

点击「备份作品包」，然后到作品库「导入作品包」。预期：分镜、照片、品牌色、封面与口播稿恢复为另一份新作品，没有历史视频。发布素材 ZIP 与可编辑作品 ZIP 用途不同。

## 恢复与边界

| 操作 | 预期 |
| --- | --- |
| 修改后刷新页面 | 出现草稿恢复提示；恢复后可继续修改并保存 |
| 在两个窗口编辑同一作品 | 旧版本保存被拒绝；可另存副本保留草稿 |
| 切换作品后打开「导出任务」 | 能看到所有当前任务与最近历史，可返回作品或下载成片 |
| 取消合成中任务 | 状态变为已取消，当前作品和照片保留 |
| 归档刚创建的测试副本 | 在归档筛选中找到并恢复 |
| 缺少照片或磁盘不足 | 导出前明确提示，不创建无法完成的正常任务 |
| 不完整或不属于本产品的作品包 | 拒绝导入，已有作品保持不变 |
| 服务重启时任务被中断 | 任务标为失败，可重新导出 |
| 服务中断后保存草稿 | 显示连接提示，草稿保留；重新启动服务并点「重新连接」后可保存 |
| 照片只有完整文件头、内容已损坏 | 预览与导出前检查提示重新上传，不把损坏照片当作可用素材 |
| 选择不同声音/画质设置 | 按新设置导出；旧结果仍在历史记录中 |

## 技术验证

本地使用 macOS / Python 3.12。核心自动测试命令：

~~~bash
.venv/bin/python -m pytest -q
node --test tests/editor.test.cjs tests/http.test.cjs
node --check web/app.js
.venv/bin/python bootstrap.py --check
.venv/bin/python doctor.py
~~~

覆盖实际 MP4 完整解码、三种 1080p 画幅、选定封面像素一致性、移动背景上的稳定文字、真实编码音量比、声音与字幕时轴、排队与取消、版本冲突、草稿副本、素材隔离、多画幅失败回滚、作品包往返与无效文件拒绝。

本地当前为 115 项 Python、12 项 JavaScript 测试通过。CI 包含 Linux Python 3.10/3.11/3.12 与 Windows Python 3.12。新增 Windows 验证发现默认编码导致中文元数据/字幕读取问题，已改为显式 UTF-8；8b823cf 和 c1fa4f6 的 CI 均成功，后续提交结果以仓库 Actions 与 [持续开发记录](OVERNIGHT_PROGRESS.md) 为准。

中文原生配音已通过本机实际导出与播放验收；自动化测试用可控音频验证时轴。DeepSeek 仅做模拟接口测试与官方协议核对，本次没有使用密钥或调用付费 API。Windows / Linux 可以输出字幕和音乐，macOS 婷婷配音为可选能力。

浏览器额外实测：停止服务 → 尝试保存 → 显示「无法连接本地服务」且文字仍在 → 重启服务 → 点击重新连接 → 原草稿保存成功。改为竖屏后查看旧方形成片，预览仍为 1:1；当前导出尺寸单独显示 9:16。

在独立临时数据库的测试服务中，主动让作品读取延迟 1 秒：打开作品后立即返回作品库或新建页，晚到的请求不会覆盖最新页面。缩略图与完整预览逐像素比对布局一致；原照片内容保持不变。预览缓存有 32 MB / 64 项上限，保存编辑或照片文件改变后重新生成。

发布 ZIP 在干净临时目录解压后，逐文件 SHA-256 校验通过；三份作品包均可导入并逐幕预览，重新生成 1280×720 带音乐视频和五件发布素材成功。这里只复用本机已安装的依赖，不等同于另一台机器完成首次联网安装。

## 数据保留

作品、照片、历史导出在 data 文件夹；首次开发前已备份已有数据库。仓库与安装包不包含用户 data、.env 或虚拟环境。完整备份先停止服务再复制 data，单作品迁移使用界面的可编辑作品包。
