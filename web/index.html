    A QUICK START

    三步，完成你的第一支短片。

    1. 填写门店信息

      填入店名、产品、特色和地址。可先用虚构咖啡店示例体验，也可切换自由创意。

    2. 打磨分镜

      为每幕上传产品、环境或门头照片，修改字幕，保存后检查裁切与文字。支持 JPG、PNG、WebP，单张不超过 8 MB、2000 万像素。

    3. 导出成片

      选择中文配音与音乐，导出视频、字幕、封面和发布文案。配音会延长过短镜头；成片以实际导出时长为准。

    当前版本的能力

    门店模式只根据填写信息套用文案模板，照片由你上传，不生成实拍画面。当前中文配音使用 macOS 已安装的婷婷语音，无需 API 密钥；其他系统仍可导出字幕与音乐。

    服务端配置 DEEPSEEK_API_KEY 后，可选择 AI 编写分镜；仅此模式会将创意发送给 DeepSeek。

    作品保存在本机 data 文件夹。此版本适合个人本地演示。

    这份作品的照片

    选择照片用于当前分镜。照片可重复使用，不会改变其他镜头。

    门店资料

    店名用于画面角标。修改资料后，请同步核对各幕字幕；已编辑的分镜文字会保留。
